# Портфолио Fullstack Разработчика

Современное портфолио fullstack разработчика, созданное с использованием React, TypeScript и Tailwind CSS с архитектурой FSD (Feature-Sliced Design).

## 🚀 Технологии

- **Frontend**: React 18, TypeScript
- **Стилизация**: Tailwind CSS
- **Роутинг**: React Router DOM
- **Архитектура**: FSD (Feature-Sliced Design)
- **Сборка**: Create React App

## 📋 Требования

Перед началом убедитесь, что у вас установлено:

- Node.js (версия 16.0 или выше)
- npm или yarn

### Установка Node.js на macOS:

```bash
# Через Homebrew (рекомендуется)
brew install node

# Или скачайте с официального сайта: https://nodejs.org/
```

## 🛠 Установка и запуск

1. **Перейдите в папку проекта**:
   ```bash
   cd client
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   # или
   yarn install
   ```

3. **Запустите проект в режиме разработки**:
   ```bash
   npm start
   # или
   yarn start
   ```

4. **Откройте браузер** и перейдите по адресу: http://localhost:3000

## 🎨 Кастомизация

### Изменение личной информации
Отредактируйте файл `src/shared/data/index.ts`:

```typescript
export const personalInfo: PersonalInfo = {
  name: 'Ваше Имя',
  title: 'Ваша Должность',
  photo: '/images/your-photo.jpg',
  // ... остальные данные
};
```

### Добавление проектов
Добавьте новые проекты в массив `projects` в том же файле.

### Изменение стилей
Проект использует Tailwind CSS. Основные настройки находятся в:
- `tailwind.config.js` - конфигурация Tailwind
- `src/index.css` - глобальные стили и компоненты

## 🚀 Сборка для продакшн

```bash
npm run build
# или
yarn build
```

Готовые файлы будут в папке `build/`.

## 📝 Примечания

- Изображения проектов и фото разработчика находятся в папке `public/images/`
- Проект содержит 5 примеров проектов с реалистичными данными
- Все текущие изображения используют плейсхолдеры - замените их на реальные
- Форма обратной связи настроена для демонстрации (добавьте backend для реальной отправки)

## 🔧 Разработка

### Добавление новых секций
1. Создайте компонент в папке `widgets/`
2. Добавьте его в главную страницу `pages/home/index.tsx`

### Добавление новых страниц
1. Создайте компонент в папке `pages/`
2. Добавьте роут в `app/index.tsx`
