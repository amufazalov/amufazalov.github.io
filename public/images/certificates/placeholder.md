# Изображения сертификатов

## Структура папок

```
public/images/certificates/
├── adobe-logo.png                    # Логотип Adobe (100x100px)
├── adobe-commerce-developer.jpg      # Изображение сертификата Adobe Commerce Developer
└── placeholder.md                    # Этот файл
```

## Рекомендации по изображениям

### Логотипы компаний-эмитентов сертификатов
- **Размер**: 100x100px или больше
- **Формат**: PNG с прозрачным фоном
- **Качество**: Высокое разрешение для четкого отображения

### Изображения сертификатов
- **Размер**: 800x600px или больше
- **Формат**: JPG или PNG
- **Качество**: Высокое разрешение для читаемости текста
- **Содержание**: Полное изображение сертификата

## Необходимые изображения

1. **adobe-logo.png** - Логотип Adobe
   - Можно скачать с официального сайта Adobe
   - Размер: 100x100px минимум

2. **adobe-commerce-developer.jpg** - Сертификат Adobe Commerce Developer
   - Сканирование или скриншот PDF сертификата
   - Убедитесь, что весь текст читаем

## Альтернативные варианты

Если изображения недоступны, компонент автоматически покажет fallback с инициалами эмитента.

## Авторские права

Убедитесь, что у вас есть права на использование логотипов и изображений сертификатов.
